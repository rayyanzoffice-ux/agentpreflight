GETTING STARTED

Run on your machine.

AgentPreflight is self-hosted and works without an account or external AI service.

1. Clone and install

git clone <your-repository-url>
cd agentpreflight
npm install
npm test

2. Start the application

npm run dev

Open http://127.0.0.1:8787 and import an exported n8n workflow JSON.

3. Scan from CI

npm run build
node dist/src/cli.js scan fixtures/broken-workflow.json --fail-on error

Docker (local only)

docker compose up --build -d

The Compose file binds to 127.0.0.1:8787. Never expose this version to an untrusted network: it has no authentication or rate limiting.

What this version cannot do

  • It does not execute nodes or evaluate workflow expressions.
  • It cannot check whether a credential exists in your n8n instance.
  • It does not test live API connectivity or execute a sandbox.
  • Security findings are best-effort static heuristics, not a security audit.

See the repository's docs/ directory for full deployment and security guidance.
