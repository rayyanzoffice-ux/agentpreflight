# Code of Conduct

AgentPreflight is an open-source developer project. We want technical discussions to be respectful, constructive, and safe for contributors with different levels of experience.

- Be respectful and assume good faith while reviewing ideas or code.
- Critique technical choices rather than people.
- Avoid harassment, threats, hate speech, and discriminatory conduct.
- Keep issues focused on reproducible bugs, user needs, and actionable changes.
- Do not disclose secrets, private workflows, or vulnerability details in public threads.
- Credit contributors and respect software licenses.

Maintainers may edit, close, or remove disruptive contributions, or limit participation where necessary. Sensitive conduct concerns should be raised through a private maintainer contact channel when available; do not publish personal details in an issue.
